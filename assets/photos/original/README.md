# Original photos

Untouched copies of photos and artwork the shop's owner sent. Never edit, move, rename or overwrite anything in here: every picture on the site is made from these by script (`scripts/make-tour-images.mjs`, recipes in `data/tour.json`), so the originals stay as the record.

Source: the WhatsApp chat with the owner. WhatsApp compresses what it sends, so these are 1080 px copies (long side up to 1920 px for tall phone shots), not the camera files. Each folder is the date the photos arrived in the chat.
