# Original photos (not in git)

This repository is public, so the owner's originals are **not** committed. Some show the old private phone number (the A-board in 03, 12 and 13, and the business cards) and a therapist's name and photograph (05).

Where they live: Gumon's OneDrive, `10-Work/SST-Sri-Siam-Thai-Therapy/originals/`, with a `SHA256SUMS` file. To work on photos, copy that folder's date folders into this directory (it is gitignored apart from this README), then run `npm run tour-images`.

Never edit, rename or overwrite an original. Every picture on the site is made from them by script (`scripts/make-tour-images.mjs`, recipes in `data/tour.json`).

Source: the WhatsApp chat with the owner, read from WhatsApp Desktop on komphet-air on 7 Nov 2026. WhatsApp compresses what it sends, so these are 1080 px copies (long side up to 1920 px), not the camera files. Do not upscale them. For sharper photos next time, ask the owner to send them as a "document" (uncompressed).
